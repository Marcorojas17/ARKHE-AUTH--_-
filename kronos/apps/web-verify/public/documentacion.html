Que es un receipt

Un receipt es un objeto JSON autocontenido que prueba que un archivo especifico existia en un arbol Merkle con una raiz especifica. Cualquiera puede verificar un receipt sin contactar a KRONOS ni a ningun servidor.

{
  "v": 1,
  "algorithm": "sha256-rfc6962",
  "fileSha256": "d1707...",
  "leafHash": "ddd2b...",
  "leafIndex": 1,
  "treeSize": 2,
  "root": "fee64...",
  "proof": [
    { "side": "L", "hash": "ddd2b..." }
  ],
  "timestamp": "2026-10-31T16:47:45.161Z"
}

Verificacion paso a paso

Dado un archivo y un receipt, la verificacion consta de tres comprobaciones:

  • 1. SHA-256 del archivoCalcular el SHA-256 del archivo. Comparar con el campo fileSha256. Si difiere, el archivo fue alterado.
  • 2. Leaf hashCalcular SHA-256(0x00 || archivo). Comparar con leafHash. Domain separation RFC 6962.
  • 3. Proof de inclusionReconstruir la raiz del arbol aplicando la proof al leafHash. Comparar con root. Si coincide, el archivo existia en ese arbol.

Especificacion de hashes

Hash de hoja

leafHash = SHA-256(0x00 || archivo)

El prefijo 0x00 distingue hojas de nodos internos. Previene que un atacante presente un nodo interno como hoja (second-preimage attack).

Hash de nodo

nodeHash = SHA-256(0x01 || hijo_izquierdo || hijo_derecho)

El prefijo 0x01 completa el domain separation. Cada nivel del arbol tiene un prefijo distinto.

Promocion de nodo impar

Cuando un nivel tiene un numero impar de nodos, el ultimo nodo se promueve al siguiente nivel sin hashear. Esto es distinto del enfoque de Bitcoin (que duplica el nodo), y evita la vulnerabilidad CVE-2012-2459.

Verificar sin KRONOS

La especificacion es publica. Cualquiera puede reimplementar la verificacion en el lenguaje que prefiera. El algoritmo es:

function verify(file, receipt) {
  if (sha256(file) !== receipt.fileSha256) return false
  const leaf = sha256(0x00 || file)
  if (leaf !== receipt.leafHash) return false
  let h = leaf
  for (const step of receipt.proof) {
    if (step === null) continue
    h = step.side === "R"
      ? sha256(0x01 || h || step.hash)
      : sha256(0x01 || step.hash || h)
  }
  return h === receipt.root
}

API publica

El paquete @kronos/sha256-verifier implementa la verificacion completa. Cero dependencias externas. Disponible como libreria y como CLI.

npm i @kronos/sha256-verifier

Uso basico:

import { seal, verifySeal } from "@kronos/sha256-verifier";
const s = seal(buffer);
const r = verifySeal(buffer, s);
// r.ok === true
